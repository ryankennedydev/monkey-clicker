## 📖 About The Game

**BananaLand Clicker** is an addictive incremental clicker game where you start as a tiny baby monkey and rise through the ranks by collecting points. Each click brings you closer to glory, unlocking powerful upgrades, legendary skins, and automation features along the way.

Built with **pure vanilla JavaScript** - no frameworks, no dependencies, just pure monkey madness! 🐵

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🐵 **8 Unique Ranks** | Progress from "Baby Monkey 🍼" to "King of Monkeys 👑" |
| 💪 **Upgrade System** | Increase points per click (+25 per upgrade) with exponential pricing |
| 🤖 **Auto-Clicker** | Earn passive income every second after purchasing |
| 🎨 **Legendary Skin** | Unlock a rare monkey skin for 10,000 points |
| 📊 **Status Panel** | Track your points per second and rank progression |
| 🎮 **Pure Vanilla** | No frameworks! Built with HTML5, CSS3, and JavaScript |

| Points Required | Rank |

| 30,000+ | 🪖 Warrior Monkey |
| 50,000+ | 🌿 Hunter Monkey |
| 75,000+ | 🧠 Smart Monkey |
| 100,000+ | 👑 King of Monkeys |

## 🕹️ How to Play

1. **Click the monkey** 🐒 to earn points
2. **Buy upgrades** ➕ to earn more points per click
3. **Purchase Auto-Clicker** 🤖 for passive earnings
4. **Unlock the Legendary Skin** 🔓 at 10,000 points
5. **Climb the ranks** 👑 to become the ultimate monkey!
