# 🐒 BananaLand Clicker

A simple monkey-themed clicker game built with vanilla HTML, CSS, and JavaScript.

## 🎮 Features
- Rank progression system (8 levels)
- Upgrade system (increase points per click)
- Auto-clicker for passive income
- Unlockable legendary skin
- Real-time stats panel

## 🕹️ How to Play
- Click the monkey to earn points
- Buy upgrades to increase earnings
- Unlock features as you progress

## 🛠️ Tech
- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Run
Just open `index.html` in your browser.
